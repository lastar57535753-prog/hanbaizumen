# 物件広告写真の補正（構造は変えない）

## 原則（必ず守る）

1. **構造は変えない。** 壁・柱・梁・窓・建具・設備・床・天井・電線・電柱・隣の建物・眺望を、足さない・消さない・形を変えない。傷・汚れ・ひび・設備の不具合も消さない（実物と違って見えるため）。
2. **やってよいのは次の4つだけ。**
   - 明るさ・コントラスト・白飛び/黒つぶれの調整
   - 色かぶりの補正（ホワイトバランス）、彩度のごく軽い調整
   - 傾きの補正（画像全体の回転と、それに伴う内側トリミング）
   - **空だけ**を青空に差し替える（曇天・白飛びの空）。空に重なる電線・枝・アンテナは残す。**太陽が写り込むほど晴れている写真と、元から青空の写真は空をそのままにする**
3. **物件写真に生成AIを使わない。** Codex の `$imagegen` や画像生成で物件写真そのものを描き直さない（窓や建具の形が変わる）。`$imagegen` を使ってよいのは「差し替え用の空の素材」（建物を含まない空だけの画像）を作るときだけ。
4. **Canva は使わない。** 補正は下の Python スクリプト（ローカル）を基本に、縦線のゆがみ補正だけ Adobe を使う（下の表）。
5. **空を差し替えた写真には注記を付ける。** 文言は「※空は画像処理により青空に差し替えています。」。台帳の「注記」列に自動で入るので、ポータルの画像コメントや図面の写真キャプションに添える。
6. **元写真は上書きしない。** 出力は必ず別フォルダ。

## どの加工をどのサービスでやるか（レクセルマンション京急蒲田310の室内4枚で検証・2026-11-23）

| 加工 | 使うサービス | 理由 |
|---|---|---|
| 明るさ・白飛び・暗さ | **Python（hosei.py）** | 4枚で約3.5秒。室内で暗くならない。Adobe 自動トーンはLDKを明るさ58→51と暗くした |
| 色かぶり（黄ばみ・青み） | **Python（hosei.py）** | 室内は電球色の温かみを残して控えめに直す設定。Adobe 自動トーンは色かぶりをほとんど直さない |
| 縦線のゆがみ・傾き | **Adobe `image_auto_straighten`（uprightMode: vertical）** | 縦線のあおりまで直せるのは Adobe だけ。Python は画像の回転（水平・垂直の傾き）だけ |
| 空の差し替え | **Python（hosei.py）** | 空の外が1画素も変わらないことを検査できる |
| 空の素材づくり | **Codex `$imagegen`** | 空だけの画像なら建物を描き直す心配がない |
| サイズ・容量の書き出し | **Python（hosei.py）** | presets.json で一括 |
| 物件写真を生成AIで描き直す | **使わない** | Codex の生成画像は、トイレ操作パネルの印字や「TOTO」の文字が別の形に描き直され、壁紙の模様も変わった。解像度も約160万画素に下がる |
| Canva | **使わない** | 方針 |

Codex に「補正して」と頼むと、生成画像を見たうえで自分で元写真に明るさ・色だけの補正をかけ直す（構造は保たれた）。ただし1枚約1分かかり、仕上がりが毎回同じにならないため、通常は Python を使う。

## 手順

### 1. 写真を手元に置く

Dropbox の物件フォルダから取る（`mcp__Dropbox__search` → `mcp__Dropbox__download_link` → `curl` で作業フォルダへ）。元フォルダには書き戻さない。

### 2. 補正を実行する

```bash
cd skills/bukken-photo-hosei
pip install opencv-python-headless Pillow numpy   # 初回だけ
python scripts/hosei.py 入力フォルダ 出力フォルダ --sky auto --preset web,zumen
```

| オプション | 意味 |
|---|---|
| `--sky off`（既定） | 空は触らない |
| `--sky auto` | 空を自動検出し、曇天・白飛びなら青空に差し替える（既に青空・太陽が写り込んだ晴天なら何もしない） |
| `--sky マスク.png` | 空のマスク（白=空）を指定。自動検出が難しい写真（木の枝が多い等）に使う。マスクは Adobe の `image_select_by_prompt`（prompt: "the sky"）で作れる |
| `--sky-image 空.jpg` | 差し替えに使う空の画像（未指定なら自動生成のグラデーション空） |
| `--clouds` | 自動生成の空に薄い雲を足す |
| `--force-sky` | 既に青空でも差し替える（太陽が写り込んだ晴天の写真は、これを付けても差し替えない） |
| `--interior` | 室内写真。少し明るめに仕上げる |
| `--no-straighten` | 傾き補正をしない |
| `--preset` | `assets/presets.json` のキー（`web`=長辺1920px・2MB以下、`zumen`=長辺3000px、`original`=元サイズ）。サイズを変えたいときはこのファイルを編集する |

外観と室内は分けて実行する（室内は `--interior`）。

### 3. 確認する（必須）

- 出力の各写真と元写真を並べて目で見る。特に**空を差し替えた写真**は、電線・木・建物の輪郭に変な縁や欠けがないかを確認する。
- スクリプトは空を差し替えるたびに「空マスクの外の画素が1つも変わっていないこと」を検査し、変わっていたら止まる（`[NG]`）。止まったら `--sky off` にするか、マスクを指定し直す。
- `出力フォルダ/hosei_log.csv` に、写真ごとの補正内容・空の扱い・注記が残る。`*_skymask.png` は差し替えた範囲（白）。

### 4. 渡す

補正済みの写真を Dropbox の物件フォルダ内の「補正済」フォルダなどに保存し（元写真とは別）、注記が必要な写真を一覧で伝える。

## 空の素材を Codex で作る（任意）

自動生成のグラデーション空より自然な空が欲しいときだけ使う。**建物・電線・鳥・太陽を含まない空だけ**を作らせる。

```bash
codex login status          # Not logged in なら codex login --device-auth（ChatGPT アカウント）
codex exec --skip-git-repo-check "\$imagegen 雲の少ない晴れた日本の冬の青空の写真。空だけ。建物・電線・木・鳥・太陽は入れない。横長 3:2。sky.png として保存"
python scripts/hosei.py 入力 出力 --sky auto --sky-image sky.png
```

同じ物件の写真は同じ空の素材で揃える。

## Adobe を使うとき（任意）

ローカルのスクリプトで足りないときだけ使う（`mcp__Adobe__adobe_mandatory_init` を最初に呼ぶ）。

- 空のマスク: `image_select_by_prompt`（"the sky"）→ マスクPNGを保存 → `--sky マスク.png`
- 縦線の歪み（あおり）補正: `image_auto_straighten`（`uprightMode: "vertical"`）
- 明るさの微調整: `image_apply_auto_tone` / `image_apply_adjustments`

Adobe の生成系の機能（塗りつぶしで物を消す、拡張で画角を足す等）は使わない。

## 使わない場面

- 物を消す・家具を置く（バーチャルステージング）・眺望を合成する依頼 → 断って理由を伝える（構造・実物と違う写真になる）
- 販売図面そのものの作成 → `property-mysoku-generator`
- ポータルへの登録 → `lastarhouse-portal-nyuko`
