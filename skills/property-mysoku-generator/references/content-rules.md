# 内容・データ転記ルール（毎回必ず守る）

徳永新太郎さん承認（2026-07-20）。**事実に基づき、不明は埋めない**が大原則。

- **専有面積は必ず壁芯**（謄本の内法は転記しない）。坪数 = ㎡ × 0.3025。
- **不明は推測せず空欄 → `【要確認】` 赤字で残す**（ペット可否・周辺施設/距離・管理費/修繕積立金 など、資料に無ければ埋めない）。
- **資料が矛盾したら両方採らず【要確認】**。他社図面は別物件の残骸が混じることがある（例：物件概要は44戸・2025年築なのに POINT欄が581戸・平成17年築）→ 矛盾ブロックは**除外**。
- **POINT / キャッチは事実ベースで自前作成**（他社の創作文を丸写ししない）。POINTは箱に収まるよう簡潔に、備考は折り返さない短い行に。
- **他社図面に転記ミスや別住戸の混入がありうる** → 面積・間取り・価格は謄本/カンテイ（一次資料）で必ず裏取り。棟内の成約事例集は**別住戸のコンプ**が混在する（持分・面積が違う行に注意）。

## 他社PDFから間取図を抽出する（自社間取図画像が無いとき）

PyMuPDF(fitz) で該当ページを高DPI（matrix 4x ≒ 288dpi）でレンダリングし、**間取図本体だけ**を `clip` で切り出す：

```python
import fitz
doc = fitz.open("競合図面.pdf")
page = doc[0]
clip = fitz.Rect(x0, y0, x1, y1)          # 間取図本体だけを囲む（座標は要調整）
mat = fitz.Matrix(4, 4)                     # ≒288dpi
pix = page.get_pixmap(matrix=mat, clip=clip)
pix.save("間取図.png")
```

- 周囲のテキスト列・青罫線・写真・会社ロゴは**含めない**。方位記号は含めてよい。
- 不要なラベル片が入ったら Pillow で白塗り。
- `間取図.png` として**物件フォルダ直下**に保存し、images.json で `is_floorplan:true` + `region_cm` で配置（比率保持で最大化）。
- 英字室名（Bedroom等）のままでも可。自社間取図があれば差し替え推奨。

## 写真キャプション / 枠割当

強い眺望あり → 眺望をヒーロー兼背景（view_hero）、残り枠に外観／リビング／キッチン／洋室／洗面／エントランス等を割当。室内写真が無い物件では共用部・眺望を棟内他住戸から流用可（その旨を締めの報告に明記）。
