# 21Cloud 物件登録代行

センチュリー21「21Cloud」での中古マンション等の物件登録を代行するワークフロー。
資料PDFからのデータ抽出 → フォーム入力 → コメント作成 → 画像コメント/カテゴリ入力 → 最終確認まで。

## 鉄則

1. **「登録・出稿」ボタンは絶対に自分で押さない。** 全入力完了後、ユーザーに確認を取り、指示があった場合のみ押す。ユーザーが自分で押すと言えばそれに従う。
2. **価格・面積・費用などの数値は必ず販売図面と照合する。** 資料間で食い違いがあれば（例: 図面6,980万円 vs フォーム6,950万円）勝手に判断せずユーザーに確認する。
3. **禁止文言に注意。** 保存時に禁止文言チェックが走る。「希少」はNG（「穴場」は通る）。他にも「完璧」「日本一」「格安」「掘り出し物」等の優良誤認系は避ける。指摘されたら言い換えて再保存。
4. **文字数は「制限ギリギリまで」が既定方針。** ただし1文字でも超えると保存できないので、入力後に必ずJSで文字数を検証する。

## 前提セットアップ

1. **Chrome MCP（mcp__Claude_in_Chrome__*）を使う。** computer-use（デスクトップ操作）ではChromeは読み取り専用なので操作不可。
2. Chrome MCPは自分のタブグループ内のタブしか操作できない。ユーザーが既に開いている21Cloudのタブを使う場合は、**「今開いている物件のタブをClaudeのタブグループにドラッグで移動してください」と依頼**し、`tabs_context_mcp`でtabIdを取得する。
3. 資料PDF（販売図面・重要事項調査報告書・謄本・間取り図等）を受け取ったら、bashサンドボックスで`pdftotext`でテキスト化して物件データを抽出する。販売図面が最重要のデータソース。

## 21Cloud画面の技術的な扱い方（重要）

### モーダルはiframeの中にある

21Cloudの入力モーダル（キャッチコピー登録、画像登録など）は動的生成される無名iframe内にある。`read_page`ではモーダル内が見えないので、`javascript_tool`で以下のパターンでアクセスする:

```js
const doc = [...document.querySelectorAll('iframe')]
  .filter(f => f.offsetWidth > 300 && !f.id).pop().contentDocument;
```

### フォーム入力はvalue設定＋イベント発火

文字数カウンタや内部状態を更新させるため、値を入れたら必ずイベントを発火する:

```js
el.value = '...';
['input','keyup','change','blur'].forEach(ev =>
  el.dispatchEvent(new Event(ev, {bubbles: true})));
```

セレクトボックスは `s.value='値'` の後 `['input','change','blur']` を発火。

### JS実行結果が[BLOCKED]になったら

行のinnerHTML等を丸ごと返すとブロックされることがある。tag/id/name/テキストなど必要な属性だけに絞って返す。

## ワークフロー

### 1. データ抽出

販売図面PDFから以下を抽出（他資料で補完）: 価格（税区分）、所在地、交通（駅徒歩・バス）、間取り・専有面積（壁芯/内法）、階数・向き、築年月・構造・総戸数、分譲会社・施工会社・管理会社・管理形態、管理費・修繕積立金・その他費用、駐車場・駐輪場、バルコニー/テラス面積と使用料、ペット可否、設備（EV・宅配ボックス等）、リフォーム履歴（年月と内容）、現況・引渡、取引態様、周辺施設（スーパー・コンビニ・学区と徒歩分数）、特記（らくらく決済21等）。

### 2. 基本項目の入力・確認

- 必須項目（画面上部の「必須残:N項目」表示）が0になるまで埋める。
- 客付可否ラジオ: `kyakuMark-0/1/2`（メインページ直下、iframe外）。通常は客付可=`kyakuMark-1`。
- テラス付きなら `terraceMenseki`（面積）と `terraceShiyouryou`（使用料、無料なら0）。
- 価格フィールドは `kakakuF`（万円単位）。ヘッダーの価格表示は保存するまで古い値のままなので慌てない。

### 3. キャッチコピー・コメント作成

キャッチコピー登録モーダルのフィールドと文字数制限は `references/form-fields.md` を参照。全フィールドを制限ギリギリまで書く。

文案の構成要素（優先順）: ①マンション名と特徴（総戸数・デザイン・分譲/施工会社）②交通（全路線・バス含む）③リフォーム履歴（年月を明記、直近のフルリフォームが最大の売り）④専用テラス等の希少設備（※「希少」という単語は使わない）⑤収納（WIC・SIC）⑥買物・学区環境⑦ペット可・管理体制⑧現況・引渡。

保存後に禁止文言ダイアログが出たら「いいえ」→該当語を言い換え→再保存。

### 4. 画像登録（画像コメント・カテゴリ）

写真の選択・挿入はユーザーが行う場合が多い。挿入済みスロットへのコメント入力とカテゴリ設定を代行する。

- コメント欄: `#imageComment_N`（20文字）と `#imageComment100_N`（100文字）のtextarea。ユーザー指定がなければ100文字欄に90〜100文字で入力。
- カテゴリ: 各スロット行内の最初のselect。値は `references/form-fields.md` の対応表参照。
- サムネイル画像は `img.left-icon`（`…th.jpg`）。**calendar.gif等のUIアイコンを掴まないよう必ず `.left-icon` クラスで選ぶこと。**

#### 写真の中身を確認するオーバーレイ手法

小さいサムネイルを判別するには、iframe内に一時オーバーレイを作って一括表示→スクリーンショット→削除:

```js
const ov = doc.createElement('div');
ov.id = 'claudeOverlay';
ov.style.cssText = 'position:fixed;top:0;left:0;width:100%;height:100%;background:#fff;z-index:99999;display:flex;flex-wrap:wrap;align-content:flex-start;';
targets.forEach(n => {
  const ta = doc.querySelector('#imageComment100_' + n);
  let row = ta;
  for (let i = 0; i < 10; i++) { row = row.parentElement; if (row.querySelector('img.left-icon')) break; }
  const img = row.querySelector('img.left-icon');
  if (img) {
    const w = doc.createElement('div');
    w.style.cssText = 'width:24%;margin:0.5%;text-align:center;';
    w.innerHTML = '<div style="font-size:18px;font-weight:bold;">#' + n + '</div><img src="' + img.src + '" style="width:100%;height:290px;object-fit:contain;">';
    ov.appendChild(w);
  }
});
doc.body.appendChild(ov);
```

1画面8枚程度ずつ表示し、確認後 `doc.querySelector('#claudeOverlay').remove()`。判別できない写真は決めつけず、拡大表示やユーザーへの確認で裏を取る。

#### 画像コメントの書き方

- 写真に写っているものと一致させる（カテゴリ表示だけを信じない。表示と中身が違うことがある）。
- 事実（リフォーム年月、面積、設備名）＋生活イメージ（「共働き世帯に嬉しい」等）の組み合わせ。
- 物件データを織り込む: 交換年月、テラス面積、管理形態、駅徒歩など。

#### 保存時のバリデーション

「画像登録完了」（aタグ）クリックで保存。**画像が入っていないスロットにカテゴリやコメントが残っていると「画像N：画像が登録されていない場合、画像種類は登録できません。」エラーになる。** 入力前に `img.left-icon` の有無で画像アリのスロットだけを対象にし、エラーが出たら該当スロットの値をクリアして再保存する。

### 5. 最終確認

- 全コメント欄の文字数を再検証（超過ゼロ）。
- 必須残0を確認。
- 未確定事項（元付情報の広告掲載可否、価格の食い違い等）を箇条書きでユーザーに報告。
- **「登録・出稿」を押すかユーザーに確認。** 押していいと言われた場合のみクリック。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| モーダルの中身が読めない | iframeパターンでcontentDocumentにアクセス |
| 文字数カウンタが更新されない | input/keyup/change/blurイベントを発火 |
| 禁止文言エラー | 「いいえ」→言い換え（「希少」→「貴重」「めったにない」等）→再保存 |
| 画像Nエラー | 空スロットのカテゴリ・コメントをクリア |
| スクショが真っ白/変な画面 | 外側ページのスクロール位置を確認し、再スクリーンショット |
| JS結果が[BLOCKED] | 返す属性を絞る |
